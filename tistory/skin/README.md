# 티스토리 스킨 — 느긋하게

## 적용 방법

티스토리 관리 → 꾸미기 → **스킨 편집** → 우측 상단 **html 편집**

1. `HTML` 탭에 `skin.html` 내용을 통째로 붙여넣기
2. `CSS` 탭에 `style.css` 내용을 통째로 붙여넣기
3. 적용

스킨을 바꾸기 전에 **기존 스킨을 백업**해 두세요. 되돌릴 방법이 그것뿐입니다.

## 이 스킨의 원칙

독자가 은퇴를 앞둔 50대입니다. 일반 블로그 기본값(15~16px)으로는 읽기 힘듭니다.

```
본문        18px   (일반 블로그 15~16px)
행간        1.9
글자색      #1a1a1a (거의 검정)
보조 글자    #5a5a5a (회색이지만 진하게)
버튼 높이    44px 이상
```

나머지 결정은 전부 여기에 맞춘 것입니다. 폰트를 줄이거나 회색을 옅게 하면 이 스킨의 이유가 사라집니다.

## 들어 있는 것

- 목록 / 글 / 댓글 / 페이지 이동 / 태그 / 관련 글
- 링크 복사 버튼 (글 제목 아래)
- 다크 모드 자동 대응
- 인쇄용 스타일 (헤더·댓글·광고 숨김)
- 애드센스 자리 (`[##_revenue_list_upper_##]`, `[##_revenue_list_lower_##]`)
- 글 하단 고정 안내문 (금융 상품을 권하지 않는다는 문구)

## 표가 중요합니다

이 블로그는 출생연도별 표를 자주 씁니다. 좁은 화면에서는 표를 잘라내지 않고 가로로 밀어 볼 수 있게 했습니다. 잘라내면 값을 못 봅니다.

## 주의

티스토리는 스킨에 필수 치환자가 없으면 저장이 안 됩니다. 이 파일에는 필요한 것이 들어 있으니 **태그를 임의로 지우지 마세요.**

```
<s_t3>, [##_page_##], <s_ad_div>, [##_revenue_list_upper_##],
[##_count_total_##], <s_index_article_rep>, <s_permalink_article_rep>
```

저장이 안 되면 어떤 치환자가 빠졌는지 오류 메시지에 나옵니다.
