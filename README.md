# 느긋하게

은퇴를 앞두고 알아둘 것들을 정리하는 블로그. `leisurely.importants-studio.com`

Hugo + PaperMod. 파이프라인이 하루 1편을 자동으로 뽑아 PR 로 올린다.

## 독자

**은퇴가 몇 년 안에 닥치는 50대.** 대개 아직 직장에 다닌다.

이 독자는 제도 용어를 어느 정도 안다. 모르는 것은 자기 경우에 어떻게 적용되는지다.
그래서 나이·가입기간·소득으로 갈리는 지점을 반드시 짚는다. 하나의 답만 주면 틀린 글이 된다.

조급하게 쓰지 않는다. 오늘 신청해야 하는 게 아니라 몇 년을 두고 준비하는 독자다.
블로그 이름이 이래서 "느긋하게"다.


## 금지선

`docs/writing-guide.md` 에 자세히 있다. 둘만 옮기면 이렇다.

- **금융 상품을 추천하지 않는다.** 제도와 한도까지만 쓴다. 특정 금융사·상품을 비교 평가하지 않고 수익률 전망을 쓰지 않는다
- **개인 수령액을 단정하지 않는다.** 가입기간·소득·출생연도에 따라 다르다

## tistory/

티스토리로 갈까 검토하다 접은 자료다. 지우지 않고 남긴다.

- `tistory/skin/` — 티스토리 스킨 (본문 18px. 50대 독자 기준으로 잡은 것)
- `tistory/to_tistory.py` — 마크다운을 티스토리 붙여넣기용 HTML 로 변환

티스토리는 2024년 2월에 Open API 를 없애 자동 발행이 안 된다. 손으로 올려야 해서
하루 1편이 상한이고, 자체 도메인은 자동이라 같은 기간에 훨씬 많이 쌓인다.
검색 권위(티스토리 DA 86 대 새 도메인 0)를 감안해도 자동화 쪽이 낫다고 판단했다.
